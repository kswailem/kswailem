How I Evaluate Code

Reliable code must do more than pass the happy path. It should meet the stated requirements, handle boundary and invalid inputs predictably, and remain understandable and maintainable.

My workflow: understand requirements → reproduce the issue → inspect the logic → test edge cases → implement or assess the fix → run regression tests → document the evidence.
